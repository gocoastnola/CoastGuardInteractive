# Round 2 — owner feedback pass (2026-10-19, late night)

Owner: tiles too small / boring (award photo!), patrol drags, trackline must stay
in view, finale must frame the whole route. "This shit is exciting!!"

## New tool
- `scripts/screen_images.py` — **image excitement screener**. Scores DVIDS photos
  (weighted action keywords: rescue swimmer, hoist, breaking ice, vessel fire,
  interdiction… vs negative: award, ceremony, handshake, poses) and only downloads
  photos clearing a threshold. Keyword score alone proved insufficient — the pipeline
  is screener → 1600px fetch → **visual pass** → install + manifest.
  Visual pass rejected: posed headshot, award certificate (twice), Mike Pence,
  a bullet held to camera, group photos, and a watercolor painting found living
  in the ship gallery as "polar-star-bow.jpg".

## Imagery (all DVIDS public domain, visually screened)
- `mission-aviation.jpg` → MH-65 Dolphin low-angle, rotors turning, hoist cable down
- `mission-sar.jpg` → split-level: survivor at the waterline, helo inbound overhead
- `mission-fire.jpg` (NEW, replaces mission-drug.jpg) → burning vessel off Islamorada
- `mission-ice.jpg` → aerial: Polar Star carving a channel through Antarctic fast ice
- `polar-star-bow.jpg` → real icebreaking photo (was a painting)
- Manifest updated with per-file credits + "screened" provenance field.

## Landing page — full redesign
- Mission mosaic: bottom strip → **full-bleed 2×2 cinematic photo wall** (inset:0).
- Per-tile Ken Burns drift (24–33s, alternating directions), staggered 1.1s pop-in.
- Seam gradients fuse tiles (no hard jagged squares); single radial scrim keeps the
  hero copy readable without greying the photos (opacity .5 → .88, saturate 1.08).
- Labels: verb-first ("Fly / Save lives / Answer the call / Go farther") with
  mission subtitles, corner-anchored per quadrant.

## Patrol pacing — boop·boop·boop
- Port cards no longer pause the voyage: card pops on arrival and the next leg
  departs 0.2s later; the card fades on its own clock overlapping the passage
  (CARD_LIFE 2.6s, canal 3.6s). Only homecoming holds 1.2s for the fanfare.
- legDuration: min(2.4, 0.9 + miles/5500) — full patrol now ~20s (was ~55s).
- Camera frames the **cumulative trackline** each leg (fullPath slice), so the
  whole voyage stays visible and grows across the world.
- Finale: fitPoints(entire route), pitch 28 — trackline fills the frame.
- Tests updated (duration bounds); 46/46 unit, 6/6 e2e, build clean.
