# Actual miniature-ship previews

These are screenshots of the implemented production build served under `/CoastGuardInteractive/`, with real OpenFreeMap resources and existing destination photographs. They are not concepts or simulated after images. The native voyage clock continued during screenshot capture, so the ship reached Honolulu while the images were taken.

- [Desktop, 1440×900](desktop-route-head.png)
- [Phone viewport, 390×844](phone-route-head.png)

Both show the original miniature red icebreaker at the end of the retained gold route, with the globe, compact photograph, Details button, cumulative mileage and attribution visible. Source photographs and the original SVG are documented in [ASSET_LICENSES.md](../../../ASSET_LICENSES.md).

The environment was headless Chromium with software SwiftShader, not a physical phone. These images demonstrate rendered composition, not hardware frame rate or audible sound quality. Raw captures and live observations are outside Git in `/workspace/coastguard-ship-marker-evidence`; the [revision report](../../PATROL-VESSEL.md) and [PR #9](https://github.com/gocoastnola/CoastGuardInteractive/pull/9) distinguish deterministic, live-resource and CI checks.
